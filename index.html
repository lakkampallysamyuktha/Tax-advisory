The Practice

A register is only useful
if it is kept honestly.

Stackly was built around a single working idea: that tax advice is a documentary discipline before it is a persuasive one. Positions are recorded. Assumptions are written down. Deadlines are owned by name.

We work with individuals, closely held businesses and finance teams who need their filings to hold up under review — not merely to be submitted on time. Every engagement begins with the same question: what will this look like to someone reading it cold, three years from now?

  • Documented positions

    Every conclusion carries its reasoning, its authority and its date.

  • Audit-ready by default

    Working papers are assembled as the work happens, not before a notice arrives.

  • Long-horizon planning

    Structures are tested across cycles, not against a single year's rate.

A restated computation that held together under review.

Engagement Method

Four movements,
in the same order,
every time.

The sequence is deliberately fixed. It is what makes the output predictable, reviewable and defensible.

  1. Intake

    Read what exists

    Prior filings, ledgers, notices and correspondence are collected and indexed before any position is formed.

    Deliverable · Document index
  2. Position

    State the argument in writing

    Each position is reduced to a short note: the facts, the provision, the reasoning and the residual risk.

    Deliverable · Position note
  3. Execution

    File, deposit, respond

    Returns are prepared and filed against the agreed position, with the working papers assembled alongside.

    Deliverable · Filed set
  4. Review

    Test it against a cold read

    A second advisor reviews the file as though seeing it for the first time, and records what would need answering.

    Deliverable · Review memo
